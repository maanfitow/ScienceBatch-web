Why ScienceBatch?

Everything you need to write world-class scientific papers

Designed from the ground up to solve the real frustrations of both traditional TeX distributions and cloud-based editors.

In-Memory RAM Compilation

Zero `.aux`, `.log`, `.synctex`, or `.out` clutter left on your drive. Tectonic and Typst compile in an isolated RAM virtual file system, streaming binary PDF bytes straight to the viewer.

Polyglot LaTeX & Typst

Seamlessly switch between XeTeX/Tectonic for LaTeX and modern Typst in the same workspace. Full support for document classes, macros, and math numbering.

Zero-Crash Worker Subprocess

Compilation tasks run inside an isolated child worker (`sciencebatch --compile-worker`). TeX syntax crashes or C-level panics will never freeze or kill your editor.

Academic Document Parity

Built-in offline support for IEEEtran, ACM art, Springer llncs, and CurVe CV. Full icon namespaces: FontAwesome 5, SimpleIcons, and Academicons.

Smart Monaco IntelliSense

Contextual autocomplete for 120+ LaTeX commands, instant auto-scanned `\cite{` keys from `.bib` files, and dynamic `\ref{` anchors.

100% Private & Autonomous

No cloud subscriptions, no downtime during conferences, and zero corporate telemetry. Your confidential manuscripts and thesis data stay strictly on your local disk.

Installation & Setup

Get up and running in seconds

Available for Linux, Windows, and macOS. Grab the pre-built installer or compile directly with Cargo and Tauri.

Debian / Ubuntu (.deb installer)

Universal Linux (AppImage)
chmod +x ScienceBatch-x86_64.AppImage && ./ScienceBatch-x86_64.AppImage

System Architecture

High performance through modern systems design

Built on Rust and Tauri v2 for microscopic resource consumption and native binary execution.

Layer 01

Frontend Studio

React 18 + Monaco Editor + PDF.js canvas running inside an ultra-lean OS Webview with minimal overhead.

Layer 02

Tauri v2 IPC Gateway

High-throughput binary streaming between the UI and backend with typed Rust commands and async progress events.

Layer 03

Isolated Compile Worker

Subprocess running Tectonic and Typst with an in-memory VFS, ensuring GUI stability and instant zero-disk compilation.
